# Thermal Catchment Area

**열노출을 반영한 보행 환경 접근성 공간 단위 제안**

> 석사 논문 연구 | 서울특별시 | 경희대학교 기후사회과학융합학과
> 최종 수정: 2026-07-17

---

## 연구 개요

보행 네트워크에서 열환경 임계값을 초과하는 링크를 완전히 제거(Hard Cut)했을 때
실질적으로 접근 가능한 공간 범위가 어떻게 변화하는가를 분석하여, **Thermal
Catchment Area(TCA)**를 새로운 보행 환경 접근성 공간 단위로 제안한다.

- **연구 지역**: 서울특별시 전체 5m(메인) — 성동구는 파일럿 겸 해상도 비교 지역
- **타임라인**: 2026-08 SCI 투고 · 2026-09-15 석사논문 제출 · 2026-09말 중간발표

## 연구 기여점 (근간 — 흔들리지 않는 기준)

| # | 기여 | 유형 |
|---|---|---|
| 1 | **Thermal Catchment Area** — 접근성을 "점수 감소"가 아니라 "도달 가능 공간 자체의 소멸"로 재정의 | 개념 |
| 2 | **Hard Cut** — 기존 연속 패널티 방식(Jia 2022·Basu 2024·Aydin 2026·Colaninno 2024)이 다루지 못한 "경로 배제" 차원을 행동증거(Melnikov 2022·Azegami 2023·Buo 2026)와 타 도메인 선례(Kar 2024)로 뒷받침 | 개념 |
| 3 | **UTCI 직접 채택 + 단일 기상값** — 데이터 한계가 아니라 연구설계·선행연구 관행·지수 설계 스케일(Bröde 2012·Brecht 2020·Lee et al. 2025)이 공통으로 뒷받침하는 방법론적 선택임을 검증 | 방법론 |
| 4 | **SOLWEIG 도시 규모 확장 + 검증** — UMEP에 없는 대용량 도메인 처리를, 이 필드도 미해결로 인정하는(Buo et al. 2026) 문제를 물리 계산 보존한 채(버퍼 타일링) 서울 전역에 적용·검증 | 방법론 |
| 5 | **해상도 강건성 검증** — 서울 5m(30m 소스) vs 5m(1m 소스, ✅검증완료: 링크 Hard Cut 일치율 99.84%) vs 성동구 1m(무타일링) vs 성동구 1m(타일링) 다단 비교 | 방법론 |
| 6 | **서울 전역(605.70km²) 규모 실증** — 선행연구 대비 드문 대규모 적용 사례 | 실증 |
| 7 | **3축 시간대 프레임** — UTCI 포화를 한계가 아니라 발견으로 재해석(아침 출근/저녁 퇴근/낮 시간대 중 포화 최고 시각) | 실증·서사 |

## 핵심 확정 파라미터

- WALK_SPEED = 4.5 km/h · TIME_BUDGET = 15분(≈1,125m)
- Hard Cut 기준: UTCI 공식 급간(Bröde et al. 2012 Table 3) — 최종 급간 값은 검토 중
- 대표 시각: 3축 프레임(아침 출근 / 저녁 퇴근 / 낮 시간대 중 포화 최고 시각) — 구체 시각 미정
- 분석 기간: 2025년 폭염일 12일(07-23~08-03) 평균

상세 규칙·용어·절대 원칙은 `CLAUDE.md` 참고.

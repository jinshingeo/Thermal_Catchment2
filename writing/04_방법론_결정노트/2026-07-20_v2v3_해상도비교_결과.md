# 서울 전체 5m — v2(30m DEM 소스) vs v3(1m DEM 소스) 해상도 강건성 검증 결과

## 1. 목적

`README.md`·`writing/03_논문구조/2026-07-17_연구기여점_정리.md`에 명시된 **연구 기여점
5번(해상도 강건성 검증)**의 실증 자료. 서울 전역 5m MRT/UTCI를 두 가지 지형(DEM)
소스로 각각 산출해 비교한다:
- **v2**: Copernicus GLO-30(30m, 오픈소스)을 1m로 보간 후 5m로 평균 다운샘플링(기존
  메인 결과, 서울 전역 5m Hard Cut/TCA 분석에 실제 사용 중인 버전)
- **v3**: 신규 확보한 진짜 1m 실측 DEM(`Seoul_merge.tif`)을 동일 파이프라인으로 5m
  다운샘플링(2026-07-17~20 서버 파이프라인 산출)

두 버전 모두 건물(건축물대장 4단계 하이브리드)·수목(산림청 임상도) 데이터는
완전히 동일하며, **지형(DEM) 소스만 다르다.**

## 2. 방법

1. **픽셀(래스터) 단위 비교**: 서울 전역 5m 격자(7,410×6,063px) 위에서 v2/v3의
   시간대별(06~19시) Tmrt·UTCI 값을 직접 비교(MAE, RMSE, 상관계수 r), 평균 래스터
   기준 Hard Cut(UTCI≥38°C, 42°C) 분류 일치율 계산
2. **링크 단위 비교**: 서울 전체 도보 네트워크(469,010개 링크)에 Colaninno et
   al.(2024) 방식(세그먼트 버퍼+zonal mean)으로 v2/v3 각각 Tmrt·UTCI를 부여 후 비교
3. **동일 스케일 확대 비교**: 차이가 거의 없는 지역(시청)과 차이가 가장 큰
   지역(도봉산)을 동일한 2km×2km 범위·동일 컬러스케일로 나란히 시각화

## 3. 결과 — 픽셀(래스터) 단위

| 지표 | Tmrt 평균 | UTCI 평균 |
|---|---|---|
| MAE | 0.290°C | 0.067°C |
| RMSE | 0.609°C | 0.141°C |
| 편향(v3−v2) | −0.019°C | −0.005°C |
| 최대 절대차 | 15.71°C | 3.64°C |
| 상관계수 r | 0.9964 | 0.9964 |

- 시간대별 상관계수는 0.928(19시)~0.994(13시) 범위, 낮 시간대가 저녁보다 더 높음
  (상세: `03_Method_C/results/compare_v2_v3_seoul_5m/hourly_v2_v3_stats.csv`)
- **Hard Cut 분류 일치율**: 38°C 기준 **99.68%**(불일치 143,902px / 44.9M px 중),
  42°C 기준 **100%**
- |차이|>5°C인 픽셀은 전체의 0.17%, |차이|>2°C는 1.04%뿐 — 극단치는 매우 희소함
- **최대 차이 위치**: 위도 37.70072, 경도 127.01986 — 도봉산(북한산국립공원 북단)
  산악지형. 5,000개 무작위 샘플 검증 결과 이 위치를 포함한 극단치 픽셀 100%가
  서울 행정경계 폴리곤 **바깥**(바운딩박스 여백)에 위치함이 확인된 것과는 별개로,
  경계 내부에서도 산지 지형에서 상대적으로 큰 차이가 관찰됨(§5 참고)

## 4. 결과 — 링크 단위 (469,010개 링크)

| 지표 | Tmrt 링크평균 | UTCI 링크평균 |
|---|---|---|
| MAE | 0.178°C | 0.041°C |
| RMSE | 0.275°C | 0.064°C |
| 상관계수 r | 0.9979 | 0.9980 |

- **Hard Cut(UTCI≥38°C) 링크 분류 일치율: 99.84%** (불일치 756개 링크 / 469,010개)
- 42°C 기준 100% 일치(양쪽 다 초과 링크 0%)
- 링크 단위가 픽셀 단위보다도 일치도가 근소하게 더 높음 — 버퍼+zonal mean
  집계 과정에서 극단치가 평활화되기 때문으로 추정(정성적 해석)

## 5. 왜 차이가 이렇게 작은가 — 구조적 설명

v2·v3 파이프라인은 다음 순서로 완전히 동일하다: **① 건물·수목을 벡터에서 1m
격자에 직접 rasterize → ② 지형(DEM)만 소스가 다름(30m 보간 vs 진짜 1m) → ③ 1m→5m
평균 다운샘플링.** 즉 두 버전이 다를 수 있는 지점은 오직 지형(맨땅 고도) 하나뿐이며:

1. DSM = 지형 + 건물높이 인데, MRT를 좌우하는 그림자·개방도 신호는 건물·수목
   데이터(완전히 동일)가 지배적이고 지형은 상대적으로 작은 보정항이다.
2. 서울 시가지 대부분은 산지가 아닌 이상 지형 기복이 완만해, 30m 보간 지형과
   진짜 1m 지형의 절대고도 차이 자체가 작다.
3. 1m→5m 평균 다운샘플링 과정에서 지형의 미세한 차이가 한 번 더 스무딩된다.

**§3의 도봉산 확대 비교(그림 `2026-07-20_zoom_compare_Tmrt.png`)가 이 설명을 직접
뒷받침한다** — v2(30m 보간)는 산지 지형이 뭉개진 완만한 텍스처로 나타나는 반면,
v3(진짜 1m)는 능선·계곡이 뚜렷한 세밀한 지형 텍스처를 보인다. 반면 시청(도심)
지역은 v2/v3가 육안으로 구분 안 될 만큼 동일하다 — 건물이 신호를 지배하는
도심에서는 지형 소스 차이가 무의미해짐을 시각적으로 확인.

## 8. 결론

**5m 계산격자에서는 지형 소스(30m 보간 vs 진짜 1m)가 Tmrt/UTCI 결과에 미치는
영향이 무시할 만한 수준이다** — 픽셀 단위 r=0.9964, 링크 단위 r=0.998, Hard Cut
분류 일치율은 픽셀 99.68%·링크 99.84%(38°C 기준). 유일하게 눈에 띄는 차이는
산악지형(도봉산 등)에 국한되며, 이는 서울 도보 네트워크의 절대다수를 차지하는
시가지 지역과는 무관하다. **이 결과는 본 연구의 메인 산출물인 v2(30m 소스 기반
서울 전역 5m 분석)가 훨씬 비용이 큰 진짜 1m 데이터를 썼더라도 결론이 달라지지
않았을 것임을 뒷받침하며, 연구 기여점 5번(해상도 강건성 검증)의 근거로 확정한다.**
